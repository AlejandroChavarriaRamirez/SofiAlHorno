# Sofi al Horno – Plataforma web de pedidos

Proyecto final de **SC-403 Desarrollo de Aplicaciones Web y Patrones** (Universidad Fidélitas).

Página web para que los clientes de Sofi al Horno puedan ver el menú, hacer pedidos, escoger la fecha de entrega y pagar, en lugar de hacerlo todo por Instagram o WhatsApp.

## Ramas

- `main`: versión estable, solo recibe cambios desde `develop`.
- `develop`: donde se unen las funcionalidades terminadas.
- `feature/nombre` y `fix/nombre`: una rama por funcionalidad o corrección, sale de `develop`.

Nadie sube directo a `main` ni a `develop`. Todo entra por pull request y lo revisa otro compañero antes de unirlo.
